# Memory

A browser-based memory game with interactive card-matching gameplay.

The project is built with HTML, SCSS and TypeScript and includes configurable game settings, different board sizes and multiple themes.

## Features

- Start screen with game navigation
- Player selection
- Different board sizes
- Multiple game themes
- Memory card matching
- Score tracking
- Current player indicator
- Exit game confirmation
- Game over and winner screen

## Technologies

- HTML
- SCSS
- TypeScript
